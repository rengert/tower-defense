# Tower Defense

Ein kleines Tower-Defense-Spiel in Vanilla HTML/CSS/JavaScript.

## Starten

```bash
python3 -m http.server 8000
```

Dann im Browser öffnen: `http://localhost:8000`

## Steuerung

- Klicke im Spielfeld auf freie Felder, um einen Turm zu bauen.
- Klicke auf **Nächste Welle starten**, um Gegner zu spawnen.
- Verhindere, dass Gegner das Ende des Weges erreichen.
